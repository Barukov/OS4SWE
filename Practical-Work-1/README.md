### Створення віртуальної машини

Параметри оперативної пам'яті обчислено за формулою `3 × 244 + 2 = 734 МБ`. Скрипт `CreateVMBarsukov.sh` створює машину `Linux of Barsukov` з одним ядром процесора, 734 МБ оперативної пам'яті, 128 МБ відеопам'яті, контролером `vboxvga`, мережею NAT і SATA-контролером `BarsukovSATA`. Шлях до VDI-образу передається першим аргументом:

```bash
chmod +x CreateVMBarsukov.sh
./CreateVMBarsukov.sh "/home/osboxes/Linux.vdi"
```

### Псевдонім Bash

Для варіанта 2 команда `touch`, яка створює файл, має псевдонім `vstanovyty`.

```bash
alias vstanovyty='touch'
vstanovyty test.txt
ls -l test.txt
```

Для автоматичної реєстрації псевдоніма рядок із файла `bashrc_fragment.txt` потрібно додати до `~/.bashrc`, після чого виконати `source ~/.bashrc`. Зняття псевдоніма з реєстрації виконується командою `unalias vstanovyty`.

### Інтерактивний скрипт

Скрипт `vstanovyty.sh` запитує назву файла, перевіряє, чи не існує об'єкт із такою назвою, і створює файл командою `touch`. Повторний запуск із тією самою назвою завершується повідомленням про помилку.

```bash
chmod +x vstanovyty.sh
rm -f detal.txt
./vstanovyty.sh
./vstanovyty.sh
```

Під час першого запуску створюється `detal.txt`, під час другого скрипт повідомляє, що об'єкт уже встановлено.
